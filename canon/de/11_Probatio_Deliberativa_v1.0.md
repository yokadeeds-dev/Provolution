### CANON-Dokument · Version 1.0 · 2026-04-09
**Autor:** Tobias Yoka Dietz

---

## 0. PRÄAMBEL

**Probatio Deliberativa (PD)** prüft ob eine politische Entscheidung SEC-J-konform getroffen wurde. Nicht ob das Ergebnis richtig ist – sondern ob der Prozess ausreichend fundiert, effizient begründet, widerspruchsfrei und gerechtigkeitssensibel war.

Kein automatischer Stop – alle vier Dimensionen werden immer vollständig bewertet.

---

## 1. ABGRENZUNG

| Merkmal | PS-U | PV | PD |
|---|---|---|---|
| Prüfobjekt | Maßnahme | Behauptung | Politische Entscheidung |
| Kernfrage | Systemisch tragfähig? | Faktisch haltbar? | Prozessual SEC-J-konform? |
| Quellenlogik | Normativ | Empirisch | Deliberativ (Protokolle, Gutachten) |
| J-Gewicht | 0,15 | 0,15 | 0,25 |
| Abbruchlogik | S-Stop | C-Veto | Kein Stop |

## 4. SEC-J-PRÜFUNG

### S · Sufficient
```
S(d) = DG(d) × Vollständigkeitsfaktor

DG-1 (mehrere Gutachten + Anhörung + Folgenabschätzung): 0,85–1,00
DG-2 (Einzelgutachten oder Ressortanalyse): 0,60–0,84
DG-3 (interne Einschätzung): 0,35–0,59
DG-4 (keine Evidenzbasis): 0,00–0,34

Vollständigkeitsfaktor: alle Perspektiven→1,00 | fehlt→0,80 | mehrere fehlen→0,60 | keine Konsultation→0,40
```

### E · Efficient
```
E(d) = 1 − (Verzerrungen × 0,20)   [min: 0,00]
Typen: Selektive Zitierung, Überinterpretation, Zeitverzug, Fachfremde Übertragung, Widerspruch ohne Begründung
```

### C · Consistent
```
C(d) = 1 − (Widersprüche / Referenzrahmen)
Referenzrahmen (mind. 3): Gesetzgebung (nat.+EU), eigene Programme, int. Verträge (Paris/SDGs), wiss. Konsens

PD-Flag: C < 0,40 → STRUKTURELLER WIDERSPRUCH (Pflichthinweis, kein Stop)
```

### J · Justice
```
J(d) = (0,20×J1) + (0,30×J2) + (0,25×J3) + (0,25×J4)
J1 Interessenkonflikt | J2 Partizipation | J3 Verteilungswirkung | J4 Vulnerabilität

J-Flag: J < 0,40 → DEMOKRATIEDEFIZIT (Pflichthinweis + Empfehlung)
```

---

## 5. AGGREGATION

```
PD(d) = (0,30×S) + (0,20×E) + (0,25×C) + (0,25×J)

J/C paritätisch (je 0,25): demokratische Legitimität hängt von Partizipation UND Konsistenz ab

Verdicts:
≥ 0,80 → KONFORM
0,60–0,79 → BEDINGT KONFORM
0,40–0,59 → DEFIZITÄR
< 0,40 → NICHT KONFORM
C < 0,40 → Flag: STRUKTURELLER WIDERSPRUCH
J < 0,40 → Flag: DEMOKRATIEDEFIZIT
```
